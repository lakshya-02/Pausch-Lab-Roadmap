# Contributing

[Home](README.md)

Contributions welcome from NTL associates and independent learners.

- Keep the format: **topic → resource → small project**.
- Prefer official docs and the creator's original video or website.
- Open links before submitting; check the destination and relevant version.
- Label paid resources and older tutorials.
- Keep new topics optional unless they are needed for the next step.
- Submit a focused pull request with the reason and verification date.

Avoid theory sections, unsupported industry claims, and duplicate resource lists.
